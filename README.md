# Timothy Ng Portfolio

A responsive, static portfolio for graduate quant developer applications. Built with HTML, CSS, and JavaScript; no build step or package installation is required.

## Preview locally

Open `index.html` directly in a browser, or serve this folder using Python:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Publish

Deploy the contents of this directory to any static hosting provider. For GitHub Pages, place these files in the repository root and enable Pages to deploy from that branch and directory. The site uses relative asset paths so it also works under a repository subpath.

## Edit

- `index.html`: visible copy, social links, education, and experience.
- `styles.css`: colors, typography, layout, and responsive rules.
- `script.js`: project case studies, project filters, interactive diagram, and contact clipboard action.
- `assets/Timothy-Ng-Resume.pdf`: replace this file to update the downloadable résumé.

Fonts are loaded from Google Fonts, with local system fallbacks if unavailable. No analytics, form submission backend, or API keys are used. Contact is through email and the supplied GitHub and LinkedIn profiles.

Project artwork is illustrative. Backtest figures are labelled as historical simulations with costs and leverage settings disclosed. Team evaluation figures are attributed to the team. The site is intended to describe graduate project work, not professional quant developer experience.

Check dates and project ownership before publishing, especially the concurrent 2023 internships and the capstone ending after the stated degree completion date.
